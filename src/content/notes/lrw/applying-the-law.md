## Signposts that keep application and explanation apart
Explanation sentences start with the case (In GTE Southwest, the supervisor…). Application sentences start with the client or the facts (Here, Kyle's calls…). Counter-analysis sentences start with the opponent (Kyle will argue…). A reader scanning the first words of each sentence should see the structure.
