  - id: state-action
    label: { en: "Is there state action?", es: "¿Hay acción estatal?" }
    test: "The Constitution restrains governments. A private employer, club or motel is reached only by statute (Civil Rights Act) or when it performs a public function or is entangled with the state."
  - id: clause
    label: { en: "Which clause?", es: "¿Qué cláusula?" }
    test: "A classification (who is treated differently) is equal protection. A liberty burdened for everyone is due process. Speech is the First Amendment. Often two apply, as in Loving."
  - id: ep-tier
    label: { en: "Equal protection: pick the tier", es: "Igualdad: elige el nivel" }
    test: "Race, national origin, state alienage classifications: strict scrutiny (compelling interest, narrowly tailored). Sex, illegitimacy: intermediate (important interest, substantially related). Everything else, including economic classifications: rational basis (any legitimate purpose, rationally related)."
    pitfall: "Equal application does not cure a racial classification (Loving); separate is not equal (Brown)."
  - id: dp
    label: { en: "Due process: substantive or procedural?", es: "Debido proceso: ¿sustantivo o procesal?" }
    test: "Procedural: notice and hearing before deprivation. Substantive: fundamental liberties (marriage, family, privacy) get strict scrutiny; economic liberty gets rational basis since 1937."
  - id: lochner-story
    label: { en: "Tell the Lochner-to-Loving story", es: "Cuenta la historia de Lochner a Loving" }
    test: "1905: liberty of contract defeats a bakers' hours law. 1937: the Court abandons economic substantive due process. 1938: footnote four reserves strict review for the political process, specific rights and discrete and insular minorities. 1954 and 1967: Brown and Loving apply that review to race. This is the answer to what distinguishes economic liberalism from civil-rights liberalism."
  - id: speech
    label: { en: "Speech: content-based or not?", es: "Expresión: ¿por contenido o no?" }
    test: "Content-based restrictions and prior restraints face strict scrutiny; time, place and manner rules need only be narrowly tailored to a significant interest with open alternatives. Expressive conduct (flag burning) is speech. Incitement loses protection only if imminent and likely."
  - id: incorporation
    label: { en: "Does it bind the state?", es: "¿Obliga al estado?" }
    test: "Through the Fourteenth Amendment, almost all of the Bill of Rights binds the states (selective incorporation, Duncan); the grand jury and the civil jury do not."
